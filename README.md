# Sirius Schedule Sync

Небольшой сервис для автоматической синхронизации расписания Университета Сириус с Apple Calendar (или любым другим календарем, который поддерживает формат ICS).

Он периодически заходит на schedule.siriusuniversity.ru, парсит расписание для указанной группы и генерирует из этого файл расписания. Календарь на телефоне или компьютере может подписаться на этот файл по HTTP и всегда держать расписание в актуальном состоянии.

## Что он умеет

- Автоматически обновлять расписание (раз в 30 минут по умолчанию)
- Формировать ссылку для подписки в iOS/macOS и других ОС
- Собирать все типы занятий: лекции, семинары, практики и экзамены
- Ставить напоминания за 15 и 5 минут до пары
- Корректно обновлять или удалять отмененные/перенесенные занятия
- Работать через прокси (полезно, если вы хостите это на зарубежном сервере, так как сайт Сириуса иногда блокирует иностранные IP)

## Как это устроено

Схема работы довольно простая:
Скрипт на Python с помощью APScheduler раз в полчаса дергает Livewire API сайта Сириуса. Полученные данные преобразуются в формат iCalendar (.ics). FastAPI сервер раздает этот файлик по HTTP. Телефон периодически запрашивает файл и обновляет события у вас в календаре.

## Как запустить

### Настройка

Для начала склонируйте репозиторий и настройте переменные окружения:

```bash
cd /path/to/lks
cp .env.example .env
nano .env
```
Там обязательно нужно указать `GROUP_NAME` (вашу группу). Если сервер находится за рубежом, возможно, понадобится прописать прокси.

### Запуск через Docker

Это самый простой способ:

```bash
docker-compose up -d
```

### Запуск без Docker

Если не хотите возиться с докером:

```bash
pip install -r requirements.txt
python server.py
```

### Как подключить на iPhone

1. Зайдите в Настройки -> Календарь -> Учетные записи
2. Выберите "Добавить учетную запись" -> "Другое"
3. Выберите "Подписной календарь"
4. Вставьте ссылку на ваш сервер: `http://ваш-сервер:8080/schedule.ics`

Телефон сам будет запрашивать обновления в фоновом режиме.

## Конфигурация

Все настройки лежат в файле `.env`. Вот основные параметры:

- `GROUP_NAME` — название группы (например, К0609-23)
- `WEEKS_AHEAD` — на сколько недель вперед собирать данные (по умолчанию 4)
- `WEEKS_BEHIND` — на сколько недель назад (по умолчанию 1)
- `UPDATE_INTERVAL_MINUTES` — как часто опрашивать сайт (в минутах)
- `SERVER_HOST` / `SERVER_PORT` — где запускать веб-сервер
- `HTTPS_PROXY` — HTTP/SOCKS5 прокси, если нужен

## Решение проблем с зарубежными серверами

Если сайт расписания отдает таймауты с вашего VPS, скорее всего IP заблокирован. Варианты решения:
- Настроить SOCKS5 или HTTP прокси (с российским IP) в переменной `HTTPS_PROXY`
- Поднять VPN до России на самом сервере
- Либо просто захостить этот скрипт на любом дешевом российском VPS.

## API

Помимо самого ICS-файла, у сервера есть несколько служебных ручек:
- `GET /` — базовая информация
- `GET /schedule.ics` — сам календарь
- `GET /health` — проверка, что сервис жив
- `GET /status` — когда было последнее успешное обновление
- `POST /refresh` — пнуть парсер, чтобы он обновил данные прямо сейчас

## Структура кода

- `config.py` — загрузка настроек
- `scraper.py` — основная логика парсинга
- `ics_generator.py` — сборка ICS-файла
- `server.py` — веб-сервер и шедулер

## Пару замечаний

- Данные берутся из публичного доступа, поэтому логин от личного кабинета не нужен.
- Не ставьте интервал обновления меньше 15 минут, чтобы не ддосить сервер Сириуса.
- Во время каникул расписание может быть пустым, это нормально.
